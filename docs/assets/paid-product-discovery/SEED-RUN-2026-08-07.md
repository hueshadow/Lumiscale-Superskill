## 初步结构观察（供 L3 供给审计，非最终结论）

1. **LTD 层**：SEO 内容、AI 写作、简易设计、课程生成、邮件助手 —— 付费意愿在 SMB 工具带反复出现，但**同质红**。适合学价格锚，不适合当蓝海灵感第一来源。  
2. **报收层**：image/headshot/thumbnail、testimonial、backlink 等「贵人工 → AI」替换叙事仍多。  
3. **PH 新品层**：AI 订阅账单治理（Toolspend）、公司任务 agent（Polsia）——更像**2026 运营痛点**，付费证据仍要长出来。  
4. **与 Toolify 关系**：Headshot / 写作 / 设计类更可能已在流量-支付探针视野；LTD 小工具与私域成交更易**落在收入榜外**。

## 建议你本机 30 分钟补做（升级证据）

对 CSV 里 `decision=track` 且等级 A/B 的域名：

1. 打开 `/pricing`  
2. 点 Upgrade，看 Checkout 域名（Stripe/Paddle/Lemon 等）  
3. 有 G2 的记评论数  
4. 能结账的 B→A；有官方 MRR 披露或可信截图的 A→S  
5. 死链或纯 free → kill 并写理由
