## 趋势分析

### 阶段一：关键词堆砌时代（2022-2023）

早期 AI 图像生成的核心 Prompt 模式：

```
"masterpiece, best quality, 8k, ultra high res, cinematic lighting, 
photorealistic, highly detailed, sharp focus, trending on artstation"
```

**特征**：质量修饰词为主，本质是**调参思维**——通过堆叠高频词提高出图质量。

### 阶段二：结构化 Prompt 时代（2024-2025）

Midjourney v6、DALL-E 3 等模型升级后，Prompt 开始结构化：

```
Subject + Action + Environment + Style + Lighting + Mood + Technical specs
```

**特征**：场景化、故事化，Prompt 从"调参"变成"写场景"。

### 阶段三：创意策划时代（2025-2026）

当前阶段，顶尖 Prompt 创作者已经在做：

| 维度 | 传统 Prompt | 进阶 Prompt |
|------|-----------|-----------|
| 构图 | 无 | 引导式构图节奏、视觉层次、主体位置引导 |
| 镜头 | 无 | 镜头语言（特写/广角/俯拍）、景深控制、动态模糊 |
| 情绪 | "moody" 一词带过 | 多层级情绪氛围设计（光线→色调→人物表情→环境细节） |
| 人物 | "beautiful woman" | 人物性格设定（微表情、肢体语言、服饰风格暗示性格） |
| 叙事 | 无 | 单帧叙事性（一张图讲一个故事瞬间） |

## PromptBase：Prompt 交易市场概述

### 平台信息

- **网址**：[promptbase.com](https://promptbase.com)
- **定位**：Prompt 买卖市场，连接创作者和用户
- **模式**：创作者上传 Prompt（含示例图），设定价格，用户购买下载
- **覆盖模型**：Midjourney、DALL-E、Stable Diffusion、ChatGPT 等

### 为什么 Prompt 能卖钱？

1. **信息差价值**：高质量 Prompt 是反复试错的结果，购买可节省大量时间
2. **复用性**：一个 Prompt 模板可生成无限变体
3. **风格壁垒**：某些视觉风格需要特定的 Prompt 组合才能稳定复现
4. **需求分层**：普通用户想获得专业级输出，但缺乏 Prompt 工程能力

### 卖得好的 Prompt 类型

| 类型 | 示例 | 价格区间 |
|------|------|----------|
| 头像/人像模板 | AI 写真、职业照、情侣头像 | $2.99 - $9.99 |
| Logo 设计 | 极简 Logo、品牌标识 | $4.99 - $14.99 |
| 产品渲染 | 电商白底图、场景展示 | $5.99 - $19.99 |

## 启示与思考

### 对创作者

1. **Prompt 本身变成了产品**——不只是出图的工具，而是可直接变现的创意资产
2. **"词库"是护城河**——积累个人的 Prompt 风格和技巧，形成差异化
3. **从"会用 AI"到"用得比别人好"**——在人人都会 AI 的时代，差异在 Prompt 深度

### 对产品人

1. **Prompt 即用户需求的语言化表达**——什么样的 Prompt 有人买，就是什么样的视觉需求有市场
2. **Prompt 市场 = 需求探测器**——热门 Prompt 类型反映市场上未被满足的视觉内容需求
3. **AI 生成 + Prompt 模板化 = 内容生产规模化**——一套 Prompt 模板可以支撑一个内容矩阵

### 对行业

1. **"AI 替代工作"的另一面**：AI 没有直接替代设计师，但把创意能力从"软件操作"转移到"语言表达"——会写 Prompt 的人正在获得新的竞争优势
2. **词库即生产力**：@serein 的感叹"AI 没抢我工作，先把我的词库抢了"精准点出了这个焦虑——知识壁垒从"会用什么工具"变成了"有什么样的词库和表达力"
