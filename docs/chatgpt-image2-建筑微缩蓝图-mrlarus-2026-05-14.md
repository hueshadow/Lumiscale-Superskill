## 视觉风格分析

从 12 张输出图片的共性中，可以推断出 Prompt 的核心视觉要素：

### 必含元素

1. **设计手稿/蓝图基底**：底层呈现建筑蓝图的网格线、尺寸标注、手绘草图线条
2. **3D 微缩模型**：建筑以实物微缩模型的形态呈现，具有纸模/木模质感
3. **施工场景**：小比例施工人员、脚手架、马车等运输工具
4. **平面图 + 剖面图**：画面包含多视角的技术图纸
5. **结构细节**：斗拱、屋面、墙体等建筑结构的分解展示
6. **营造现场感**：工作台、工具、材料等周围环境元素

### 视觉技巧

- **从「设计手稿」到「实体模型」的过渡**：底部/左侧是蓝图，顶部/右侧是建成的模型——形成「从图纸到现实」的视觉叙事
- **等距/轴测视角**：微缩模型采用类似建筑效果图的等距视角（isometric）
- **暖色调 + 纸张纹理**：整体呈现档案级、博物馆展品般的质感
- **比例对比**：施工小人的微小尺寸与建筑的宏伟形成冲击力

## Prompt 模式推断

基于 @MrLarus 公开分享的相似作品和 ChatGPT-Image2 的能力边界，可以推断 Prompt 的核心框架：

### 推测 Prompt 结构（中英混合）

```
[建筑名称] 的微缩建筑模型蓝图，包含：
- 底层：手绘设计草图/建筑蓝图（网格线、尺寸标注、剖面线）
- 中层：3D 微缩模型正在建造中（纸模/木模质感）
- 顶层：已完成的建筑细节，等距/轴测视角
- 施工小人（1:100 比例）、木质脚手架、运输马车
- 暖色纸张纹理、博物馆展品灯光
- 建筑学术档案风格、工程图纸美学
```

### ChatGPT-Image2 关键参数（推断）

- **画幅比**：1024×1536（竖版 2:3），适合手机浏览和展示建筑纵向结构
- **风格关键词**：architectural blueprint，isometric，papercraft，diorama，museum archive，construction in progress
- **参考风格**：类似「paper architecture」「exploded axonometric」「architectural model kit」

## 传播策略拆解

这个系列为什么能获得高传播？

### 1. 「工具性内容」驱动书签和转发

- **324 个书签**（Layer 2）→ 用户标记以备用，说明 Prompt 具有实际使用价值
- @MrLarus 主动将 Prompt 放入评论区而非主帖正文 → 促进回复数增长 → X 算法提升曝光
- Quote Chain 串联 → 用户从任意一层进入都会被引导至其他层，增加总停留时间

### 2. 视觉新奇感 + 中国文化共鸣

- 微缩模型 + 中国古建筑 → 既有技术新鲜感，又有文化认同
- 「施工现场」概念打破常规 AI 生图的「成品展示」模式，增加故事性
- 布达拉宫、太和殿等具有全民认知度的选题，覆盖面广

### 3. 系列化内容建立期待

- 4+4+4 的结构让受众在看完一批后期待下一批
- 从自然景观（Layer 1）到古建筑（Layer 2/3），主题递进
- 每批 4 个是信息密度的 sweet spot——不多到 overwhelm，不少到觉得敷衍
