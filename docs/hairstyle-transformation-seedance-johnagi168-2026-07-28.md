## 方法论拆解（为什么稳）

### 1. 锁死不变项

| 锁定项 | 写法 | 作用 |
|--------|------|------|
| 背景 | 暖米色无缝影棚全程不变 | 避免每镜重绘场景导致跳变 |
| 布光 | 正面柔光箱 + 发丝轻微轮廓光 | 写真感一致，发丝分离度高 |
| 机位 | 固定竖屏中近景（胸口以上）居中 | 省算力给脸与发型，切镜不晃 |
| 脸 | 女主@图片1，面部全程一致 | 图生视频身份锚点 |
| 转场 | 全片同一 Turn + Hair Whip | 变装合法化，遮住 morph 瑕疵 |

**原则**：变的是发型/服装/小动作；不变的是脸、光、景、机位、转场语法。

### 2. 转场即遮瑕（Turn + Hair Whip）

流程：

```
正面亮相（报发型名 + 字幕）
    → 侧后转身甩头
    → 发丝高速运动模糊短暂遮脸
    → 硬切
    → 新发型新服装正面
```

这比「淡入淡出」或「无遮挡硬切」更适合当前视频模型：

- 模糊帧掩盖 identity morph 的中间态
- 甩头提供物理动势，卡点感强
- 同一机制重复 9 次，观众迅速建立「规则预期」，不觉得乱

### 3. 分镜粒度：1 秒一级

10 秒塞 9 变装，几乎「一秒一 look」。能成立是因为：

- 每镜只要求 **一个辨识动作**（报幕 / 打招呼 / 比心 / 挑眉）
- 信息密度在 **发型名 + 服装标签**，不靠长台词
- 旁白短词：「黑长直。」「羊毛卷。」……便于 Seedance 音画同出

### 4. 服装与发型绑定叙事弧

从日常 → 职场 → 运动 → 甜美 → 洛丽塔 → 利落超短，形成情绪递进，而不是随机堆发型名。结尾超短发 + 定格 = 强记忆点（反差最大）。

### 5. 音效设计写进 Prompt

- 底：轻快卡点 BGM  
- 每次甩头：破风「呼」+ 卡点「咔」  
- 结尾：上扬收束音 + 定格  

Seedance 2.0 支持音画同出时，把 SFX 写进 prompt 比后期干贴更齐。

## 使用说明（Seedance 2.0）

1. 准备 **清晰正脸参考图**（@图片1），光照尽量接近影棚柔光  
2. 粘贴完整中文 prompt  
3. 时长选 **10 秒**，画幅 **9:16**  
4. 若模型支持「角色参考 / 图片参考」，务必挂上同一张脸  
5. 生成后检查：  
   - 脸是否串脸  
   - 甩头是否真的遮脸再切  
   - 9 个发型名旁白/字幕是否对齐  
   - 结尾是否定格  

### 常见翻车与改法

| 问题 | 可能原因 | 改法 |
|------|----------|------|
| 中途换脸 | 参考图弱 / 未挂图 | 更清晰正脸；强化「面部特征全程一致」 |
| 变装像溶解 | 无有效遮脸 | 加长「头发高速甩动遮挡面部」描述 |
| 背景乱跳 | 未锁背景 | 重复「暖米色无缝背景全程不变」 |
| 超时挤不下 9 镜 | 模型偏慢节奏 | 减到 6–7 镜，或时长改 12–15s |
| 字幕乱码 | 模型字幕弱 | 去掉字幕只保留旁白，或后期贴字 |
| 发型名念错 | 多音/生僻 | 旁白用更口语写法，或英文 tag |
