## 背景：Vibe Coding × 3D Web 作品集

### Vibe Coding（氛围编程）在说什么

行业常见定义（2025–2026 语境）：用自然语言描述需求，让模型生成/改代码，人主要负责方向、审美验收与迭代，而不是逐行手写。适合：

- 作品集站、landing、小工具  
- 快速验证交互与视觉  
- Creative Coding 原型  

### 3D 个人站常见技术栈（行业对照，非作者公开清单）

本帖未写死技术细节；同类项目常见组合：

| 层 | 常见选择 |
|----|----------|
| 3D 运行时 | Three.js / React Three Fiber / WebGL |
| 角色/场景 | 自建 glTF、AI 生成网格后再精修、Spline 等 |
| 前端壳 | React / Next / 纯 Vite |
| 样式 | Tailwind 等 |
| 生成路径 | Cursor / Claude Code / Gemini / 其它 agent 对话式改站 |
| 部署 | Vercel / Netlify / Cloudflare Pages 等 |

作者 bio 强调 **AI Coding & WebGL & Creative Coding & CG Design**，与「3D 小人个人站」高度一致——这不是纯 no-code 拼图，更偏 **会 CG/WebGL 的人用 Vibe 加速**。

### 为什么「3D 虚拟小人」特别适合当简历钩子

1. **身份可视化**：观众 1 秒记住「人」而不是「又一个 portfolio 模板」  
2. **技能自证**：WebGL/互动/审美一次性展示  
3. **可玩性**：停留时长与录屏传播天然高于静态页  
4. **AI 叙事完整**：形象可走 AI 生成/绑定，站点可用 Vibe Coding 搭——故事一条线讲完
