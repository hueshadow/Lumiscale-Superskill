## 如何使用

### 快速安装（推荐 Claude Code）

```bash
git clone https://github.com/msitarzewski/agency-agents
cd agency-agents
./scripts/install.sh --tool claude-code
```

### 支持的工具矩阵

该项目已适配 **11 种主流 AI 编程工具**：

| 工具 | 安装命令 |
|------|---------|
| Claude Code | `./scripts/install.sh --tool claude-code` |
| Cursor | `./scripts/install.sh --tool cursor` |
| GitHub Copilot | `./scripts/install.sh --tool copilot` |
| Gemini CLI | `./scripts/install.sh --tool gemini-cli` |
| OpenCode | `./scripts/install.sh --tool opencode` |
| OpenClaw | `./scripts/install.sh --tool openclaw` |
| Aider | `./scripts/install.sh --tool aider` |
| Windsurf | `./scripts/install.sh --tool windsurf` |
| Antigravity | `./scripts/install.sh --tool antigravity` |
| Qwen Code | `./scripts/install.sh --tool qwen` |
| Kimi Code | `./scripts/install.sh --tool kimi` |

### 手动使用

每个 Agent 都是一个 Markdown 文件，包含完整的身份设定、人格特征、核心使命、工作流程和成功指标。可以直接复制粘贴到任何 LLM 对话中作为 System Prompt 使用。

## 核心价值分析

### 为什么值得关注

1. **角色即基础设施**。这不是简单的 Prompt 模板集合，每个 Agent 都有独立的人格设定、工作流程和交付标准。相当于把「给 AI 写 Prompt」这件事标准化和工程化了。

2. **社区驱动的设计模式库**。147 个角色来自全球贡献者，代表了当前 AI Agent 角色设计的最佳实践合集。研究这些角色文件本身就是学习「如何设计 AI Agent」的最佳教材。

3. **即插即用的生产力杠杆**。尤其是对独立开发者和小团队，可以直接用这些角色组建「虚拟团队」——安全审查、代码审查、UI 设计、SEO 优化，都不需要招人，激活一个 Agent 就行。

### 与中国市场的关联

- **中文翻译版**已由 [@jnMetaCode](https://github.com/jnMetaCode) 维护，包含 141 个翻译角色 + 46 个中国本土原创角色
- 已覆盖**微信小程序、飞书集成、小红书、B站、抖音、知乎、百度 SEO、跨境电商、直播电商、私域运营**等中国平台
- 对运营中文社交媒体（公众号、小红书等）的团队有直接实用价值
