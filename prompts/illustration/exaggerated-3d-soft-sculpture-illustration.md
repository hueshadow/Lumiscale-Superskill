## 使用说明

### 适用工具
- ChatGPT / GPT Image
- 可将英文 Prompt 翻译为中文后在 ChatGPT 原生界面使用（效果可能略有差异）

### 关键参数

| 参数 | 值 |
|------|-----|
| 构图 | 单人 3D 插画，非分镜/拼贴 |
| 角色比例 | 小头、圆胖身体、极长四肢、大手大脚 |
| 姿势 | 戏剧性跳跃、空中悬停、重心失衡 |
| 材质 | 磨砂软胶、毛绒织物、针织纹理、橡皮泥感 |
| 配色 | 高饱和多巴胺色系，大色块碰撞 |
| 背景 | 纯白、极简、仅地面椭圆阴影 |
| 灯光 | 柔光工作室灯光、全局照明、低对比 |
| 渲染风格 | C4D/Blender 3D，软雕塑风格 |

### 适配方法

1. **替换主题**：将最后一段 `Theme:` 后的描述替换为你的场景
2. **保持风格段不变**：前面的材质、配色、灯光、角色比例描述是风格核心，不要改动
3. **负面约束已在 Prompt 内**：已包含 `avoid glossy plastic toy look, avoid translucent glass look, avoid high reflections`

### 风格特征总结

- **造型**：软雕塑玩具感，圆润、有弹力、夸张非写实
- **材质**：拒绝光滑塑料/玻璃/高反光，追求手工感
- **色彩**：多巴胺配色，大胆撞色，明亮不刺眼
- **氛围**：商业插画质感，编辑级品质，趣味性强
